# Fragments — 微信小程序版

这是把 `index.html`（单文件网页版）移植成的微信小程序版本，两者不是同一份代码——小程序用的是微信自己的 WXML/WXSS/JS 框架，跟网页完全是两套技术栈，所以这是一次重写，不是转换。核心数据结构、合并算法、AI 提示词（`utils/prompts.js`）都和网页版逐字/逐段对应，行为应该是一致的。

## 这几步只有你自己能做

我没有微信开发者账号，也没有 WeChat 开发者工具（一个桌面软件），下面这几步必须你自己完成：

1. **注册小程序开发者账号**：去 [mp.weixin.qq.com](https://mp.weixin.qq.com) 用身份证（个人）或营业执照（企业）注册一个小程序。个人主体有一些功能限制（不能用支付、部分类目不开放），但发一个纯工具类小程序够用。
2. **拿到 AppID**：注册完成后，在小程序后台「开发管理 → 开发设置」能看到你的 AppID。把它填进 `project.config.json` 里的 `"appid"` 字段，替换掉现在占位用的 `"touristappid"`。
3. **配置服务器域名白名单**：这是最容易被忽略、也最容易导致"怎么点都没反应"的一步。去小程序后台「开发管理 → 开发设置 → 服务器域名」，把你打算用的 AI 服务商的接口域名加进 `request合法域名` 列表，比如：
   - `https://api.anthropic.com`
   - `https://generativelanguage.googleapis.com`
   - `https://api.openai.com`
   - 或者你实际会用的那个服务商的域名
   域名必须是 HTTPS。没加进白名单之前，请求会在离开小程序之前就被平台直接拦掉——界面上看到的报错会提示检查白名单（见 `utils/i18n.js` 里的 `errNetwork`）。
4. **用微信开发者工具打开**：下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，选择"导入项目"，目录选这个 `miniprogram/` 文件夹，AppID 填你自己的。
5. **提交审核、发布**：开发调试没问题之后，在开发者工具里点"上传"，然后去小程序后台提交审核。审核通过才会真正对外可用。

## 跟网页版相比，这个版本少了什么

移植过程中主动砍掉、或者暂时没做的几样：

- **本地模型（Ollama / LM Studio）**：网页版支持连你电脑上跑的本地模型，但小程序运行在手机上，够不着你电脑的 `localhost`，这条路径直接不通，已从服务商列表里去掉。
- **语音输入**：网页版用浏览器自带的 Web Speech API，小程序要做语音输入得接微信自己的录音+识别接口，这次没做。
- **示例分享卡片（下载 PNG）**：网页版有一个"生成分享图片"的按钮。小程序里更合适的做法是用系统自带的「转发」（右上角 ⋯ → 转发给朋友），代码里已经接了 `onShareAppMessage`，点"转发"能把词云页分享出去；生成自定义封面图（用 canvas 画一张跟网页版一样的卡片）是一个值得做但这次先没做的加强项。
- **导出 / 导入数据**：网页版是下载/选择一个 JSON 文件。小程序里文件系统 API 更麻烦，这版先做成"复制到剪贴板 / 从剪贴板导入"，能备份和搬家，只是操作上没有文件那么直观。

## 这个版本新增/保留了什么

- 首次打开的说明卡、"查看示例"预览模式（示例数据不会污染你的真实存档）、8 条记忆后长按解锁"方向"标签、记忆删除+撤销——这些网页版加过的功能都在。
- AI 接口还是"你自己配置 Key"的模式，没有变成小程序官方托管一个共享 Key——那种模式需要你自己出钱养一个后端，是完全不同的运营方式，之前讨论过不是这次要的方向。
- 长按标题 1.2 秒进设置页这个隐藏入口，也保留了。

## 目录结构

```
miniprogram/
├── app.js / app.json / app.wxss     # 小程序入口
├── project.config.json               # 开发者工具的项目配置(需要填你自己的 appid)
├── sitemap.json
├── utils/
│   ├── i18n.js       # 中英文文案、服务商列表、方向词表
│   ├── prompts.js    # AI 提示词,跟网页版逐字一致
│   ├── ai.js         # 调用 AI 接口(wx.request)
│   └── store.js      # 数据模型、合并算法、示例数据
└── pages/
    ├── home/         # 首页:记录 + 分析结果
    ├── surface/      # 我1 词云
    ├── deep/         # 我2 词云(含长按解锁方向)
    ├── memories/     # 记忆清单(含删除/撤销)
    ├── memory/       # 单条记忆详情
    └── settings/     # AI 接口配置、数据管理、边界说明
```
