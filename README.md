# 我是谁？

一次一句话地说出记忆碎片，AI 把每一段拆解成"当时那个人"的性格特性，逐条累积成两张词云：**我1** 是日常能听懂的浅层词，**我2** 是心理学构念的深层词。

这个仓库里只有一个文件：`index.html`。没有构建步骤，没有服务端，没有依赖。

## 怎么用

下载 `index.html`，双击用浏览器打开。不需要安装 Node、不需要 `npm install`、不需要起服务器——浏览器直接把它当一个网页跑起来。

## 怎么配 Key

首页看不到任何"设置"入口，这是刻意的。**长按标题 1.2 秒**会进入隐藏的设置页，在那里选服务商、填 API Key、选模型。

支持的服务商包括：

- Anthropic Claude、Google Gemini、OpenRouter（浏览器可直连）
- OpenAI、Groq、SiliconFlow（多数情况下也能直连）
- DeepSeek、Moonshot Kimi、智谱 GLM、阿里通义千问（官方接口不允许浏览器直连，需要在设置页填一个跨域中转地址）
- 本地 Ollama、本地 LM Studio（需要各自开启 CORS）
- 或任意自定义的 OpenAI 兼容 / Anthropic 兼容接口

设置页里对每个服务商是否需要中转都有提示。

## 关于 Key 的实话

Key 只保存在**这台设备这个浏览器**的 `localStorage` 里，请求由浏览器直接发到模型接口，没有任何服务端会经手你的 Key。

这意味着：

- 自己在自己的设备上用完全没问题
- 一旦你在某个 `index.html` 副本里填过 Key，**这份文件就带着你的 Key**——不要把它发给别人，也不要把它提交进仓库、传到网盘或任何公开的地方
- 这个仓库里发布的 `index.html` 必须始终是空配置的（未配置任何 Key）

## 数据存在哪

所有记忆、词云、方向标签也都存在 `localStorage` 里，不会上传到任何地方。换设备使用时，在设置页用**导出 / 导入 JSON** 搬运数据。

## 边界

- 只整理你说过的内容，不补写、不推测你没讲过的经历
- 浅层词如实描述故事里当时那个人，好听的和不好听的都给
- 深层构念是描述性的心理学概念，不是诊断
- 方向标签需要积累到一定记忆量、并在词云上长按后才会出现，标注为"非确诊"，不代表你有任何疾病
- 识别到自伤/自杀等严重危机信号时，只显示关心文案，不做画像分析
